# إجازاتي — تقويم إجازات المدارس 1448–1449 هـ

تطبيق عربي للجوال يتضمن العد التنازلي للإجازة القادمة، التقويم الهجري والميلادي، خطط الإجازة المحفوظة على الجهاز، وإمكانية تصدير الإجازات إلى التقويم.

## النشر عبر GitHub Pages

من المستودع اختر Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)، ثم Save.

بعد النشر: https://drburghash-sys.github.io/school-holidays-/

**تنبيه:** الإجازات الإضافية غير المؤكدة تظهر منفصلة، ويجب مراجعة التحديثات الرسمية. المواعيد في التطبيق ثابتة ولا تتحدث آلياً.

[التقويم الدراسي لوزارة التعليم](https://www.moe.gov.sa/ar/education/generaleducation/Pages/academicCalendar.aspx)
